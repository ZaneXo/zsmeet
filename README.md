# zsmeet

开源、自己部署的会议纪要系统：把会议录下来，自动转成带说话人和时间的文字，再用大模型写成纪要。事后想知道「这件事当时是谁、在哪场会上、怎么定的」，搜一个词或者问一句就能找到那场会议，从下结论的那句话开始听。

> 项目还在早期，还没做的见[路线图](#路线图)。

## 为什么做它

产品和开发之间常有这样的时候：迭代了几个版本以后，对某个功能该怎么做有了分歧。翻 PRD，里面没写这一点，它是在某次会上口头定下来的。可那是哪一场会？谁拍的板？原话是怎么说的？过了这么久，每个人的记忆都模糊了，各说各的。

zsmeet 就是为这种时候做的：平时开会都录下来，转成文字、写成纪要；有了分歧，很快找到那场会议，定位到是什么时候、谁下的结论，把原话放出来听。

## 怎么找到当时的结论

### 平时开会

1. **录下来**：在网页上录，或者用 [macOS 桌面版](docs/desktop-guide.md)把飞书、腾讯会议、Zoom 里对方的声音和麦克风一起录下来，也可以会后上传录音。录音时页面上边录边出字，说到关键的地方点一下就能标重点；接上飞书的话，飞书会议的云录制会自动导进来。
2. **转成文字**：每句话都有开始和结束的时间，按声音区分是谁在说。普通话、粤语、英语、日语、韩语混着说也能认；专有名词按热词读音和上下文校对。给「说话人 2」改一次真名，打开声纹以后，之后的会议会按声音自动认出他。
3. **写成纪要**：大模型按模板写出讨论了什么、定了什么、谁去做，每一条都标着时间点，点一下就跳到录音里那个地方。纪要每改一次、每重新生成一次都是一个新版本，旧的一直留着。

### 有分歧的时候

- **搜**：在所有会议的标题、纪要和转写原文里找，直接列出命中的那句话、谁说的、几分几秒，点一下从那句话前几秒开始播放。转写把专有名词听错了（「飞书」听成「非书」）也搜得到。
- **问**：直接问「导出的 Word 里要不要带时间戳，最后是怎么定的？」，大模型从会议里找答案。回答里的每个出处都写着是哪场会议、几分几秒、原话是什么，点一下就能听到当时是谁说的。

### 其他特点

- **一条命令部署**：`docker compose` 起三个容器（数据库、网页和接口、后台处理），不需要 GPU。
- **中英双语**：网页、桌面版、报错提示和导出的文档跟随系统语言切换简体中文 / English，也能在设置里自己选；纪要和问答跟随会议或提问的语言。
- **接上团队在用的工具**：纪要推到飞书群、导入成飞书文档，用飞书扫码登录；也能发到钉钉、企业微信、Slack 的群里。

## 数据会不会出网

取决于你在「设置」里接了什么——既可以完全跑在内网里，也可以接在线接口换更好的效果：

| 环节 | 不出内网的做法 | 会出网的情况 |
|---|---|---|
| **语音识别** | 默认在本机 CPU 上识别（SenseVoice），录音不离开你的服务器 | 在「设置 → 语音识别」里开启在线语音识别（DeepSeek）后，**转写时录音会分段发到外网**（实时字幕、区分说话人和声纹仍在本机算） |
| **写纪要、校对、问会议** | 接内网自己部署的 Ollama、vLLM，转写文字不出内网 | 接在线大模型接口（DeepSeek、OpenAI 等），转写出来的文字会发给它 |
| **群推送与云录制** | 不配飞书和群机器人，只在网页或桌面版里看 | 配了飞书或钉钉 / 企业微信 / Slack 群机器人，推纪要、拉云录制时会请求对应平台 |

第一次处理会议时，后台会从 Hugging Face（连不上时自动换国内镜像）下载约 300 MB 的本地识别模型，之后不再联网下载；macOS 桌面版打开后会从 GitHub Releases 检查有没有新版本（不带任何账号或会议数据）。

## 快速开始

### 1. 部署服务器

需要一台装了 Docker 的服务器（x86 的 Linux，或者 Apple 芯片的 Mac 装 Docker Desktop / OrbStack），建议 4 核 CPU、8 GB 内存以上。

```bash
git clone https://github.com/ZaneXo/zsmeet.git && cd zsmeet/deploy
cp .env.example .env
# 编辑 .env，填两个密码（文件里有生成方法），并取消注释 ZSMEET_IMAGE=ghcr.io/zanexo/zsmeet:0.1.0
docker compose pull && docker compose up -d --no-build
```

> 想直接从源码在本机编译的话，不用设 `ZSMEET_IMAGE`，把最后一行换成 `docker compose up -d --build` 即可。

然后用浏览器打开 `http://服务器地址:8080`：

> 部署好以后马上创建管理员账号：在第一个人创建管理员之前，任何能打开这个地址的人都可以成为管理员。服务器开放在公网上的话，先配好 HTTPS 再打开（见[部署 → HTTPS 和反向代理](docs/deploy.md#https-和反向代理)）。

1. 创建管理员账号。
2. 在「设置 → 大模型」里填接口地址、模型名和 API Key（任何 OpenAI 兼容接口都行；不填也能用，只是只有转写、没有纪要）；要用在线语音识别也在「设置 → 语音识别」里打开。
3. 回到「会议」，开始录音，或者上传一段录音。
4. 在「设置 → 成员」里邀请同事。

要在网页上录音，前面得加一层 HTTPS。升级、备份、HTTPS 和反向代理，见[部署和运维](docs/deploy.md)。

### 2. 安装 macOS 桌面版（可选）

要连同飞书、腾讯会议、Zoom 里对方的声音一起录，到 [Releases](https://github.com/ZaneXo/zsmeet/releases) 下载 `desktop-v*` 下的 `.dmg` 安装包（macOS 14.4 及以上，Apple 芯片和 Intel 通用），把 zsmeet 拖进「应用程序」，打开后填上服务器地址登录就能用。第一次打开的放行和录音权限见[桌面版](docs/desktop-guide.md)。
