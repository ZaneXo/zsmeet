# zsmeet

开源、自己部署的会议纪要系统：把会议录下来，自动转成带说话人和时间的文字，再用大模型写成纪要。事后想知道「这件事当时是谁、在哪场会上、怎么定的」，搜一个词或者问一句就能找到那场会议，从下结论的那句话开始听。

> 项目还在早期，还没做的见[路线图](#路线图)。

## 为什么做它

产品和开发之间常有这样的时候：迭代了几个版本以后，对某个功能该怎么做有了分歧。翻 PRD，里面没写这一点，它是在某次会上口头定下来的。可那是哪一场会？谁拍的板？原话是怎么说的？过了这么久，每个人的记忆都模糊了，各说各的。

zsmeet 就是为这种时候做的：平时开会都录下来，转成文字、写成纪要；有了分歧，很快找到那场会议，定位到是什么时候、谁下的结论，把原话放出来听。

## 怎么找到当时的结论

**平时开会**

1. **录下来**：在网页上录音；用 macOS 桌面版录，飞书、腾讯会议、Zoom 里对方的声音也一起录；或者会后上传录音。接上飞书的话，飞书会议的云录制会自动导入。
2. **转成文字**：每句话都有开始和结束的时间，按声音区分是谁在说。给说话人改一次名字（把「说话人 2」改成真名），打开声纹以后，之后的会议会按声音自动认出他。
3. **写成纪要**：大模型按模板写出讨论了什么、定了什么、谁去做，每一条都标着时间点，点一下就跳到录音里那个地方。纪要每改一次、每重新生成一次都是一个新版本，旧的一直留着。

**有分歧的时候**

- **搜**：在所有会议的标题、纪要和转写原文里找，直接列出命中的那句话、谁说的、几分几秒，点一下从那句话前几秒开始播放。转写把专有名词听错了（「飞书」听成「非书」）也搜得到。
- **问**：直接问「导出的 Word 里要不要带时间戳，最后是怎么定的？」，大模型从会议里找答案。回答里的每个出处都写着是哪场会议、几分几秒、原话是什么，点一下就能听到当时是谁说的。

另外：

- **录音不出你的服务器**：语音识别在本机 CPU 上完成，不调用外部服务。只有转写出来的文字会发给你配置的大模型；用自己部署的模型（Ollama、vLLM），数据就完全不出内网。
- **一条命令部署**：`docker compose up -d`，三个容器（数据库、网页和接口、后台处理），不需要 GPU。
- **接上团队在用的工具**：纪要推到飞书群、导入成飞书文档，用飞书扫码登录；也能发到钉钉、企业微信、Slack 的群里。

## 快速开始

需要一台装了 Docker 的服务器（x86 的 Linux，或者 Apple 芯片的 Mac 装 Docker Desktop / OrbStack），建议 4 核 CPU、8 GB 内存以上。

```bash
git clone https://github.com/ZaneXo/zsmeet.git && cd zsmeet/deploy
cp .env.example .env
# 编辑 .env，填两个密码（文件里有生成方法）
docker compose up -d --build
```

然后用浏览器打开 `http://服务器地址:8080`：

> 部署好以后马上创建管理员账号：在第一个人创建管理员之前，任何能打开这个地址的人都可以成为管理员。服务器开放在公网上的话，先配好 HTTPS 再打开（见[部署 → HTTPS 和反向代理](docs/deploy.md#https-和反向代理)）。

1. 创建管理员账号。
2. 在「设置」里填大模型的接口地址、模型名和 API Key。任何 OpenAI 兼容的接口都行；不填也能用，只是只有转写、没有纪要。
3. 回到「会议」，开始录音，或者上传一段录音。
4. 在「设置 → 成员」里邀请同事。

要在网页上录音，前面得加一层 HTTPS。升级、备份、HTTPS 和反向代理、用发布好的镜像，见[部署和运维](docs/deploy.md)。

## 路线图

接下来：

- **桌面版收尾**（正在做）：录音的回声消除、换了默认麦克风时跟着换、麦克风自动增益、App 内自动更新、在 GitHub 上发布安装包都写好了，正在真机上试。回声消除先作为默认关着的实验功能，在外放开会时试好了再默认打开。
- **国际化**：
  1. **界面多语言**：先做英文。默认跟随浏览器和电脑的语言，也能在设置里自己选。
  2. **报错和提示多语言**：服务器返回的报错、参数校验的提示、界面上的提示和说明文字，都按用户选的语言显示。
  3. **多语种混合识别**：一场会议里中文、英文（以及粤语、日语、韩语）混着说，也能准确转写。现在识别语言默认固定为中文（`ZSMEET_ASR_LANGUAGE`），因为让模型自动判断语言时，很短的语气词容易被认成日语。
- **实时字幕**：开会时边录边出字。
- **GPU 加速**：服务器有 NVIDIA 显卡时，转写和说话人区分用 GPU 跑，处理得更快。

已知的不足见[使用说明](docs/usage.md#已知的不足)和[桌面版](docs/desktop-guide.md#已知的不足)。
